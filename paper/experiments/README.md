# Experiments — Test Sets

Сюда складываем:
- **Размеченные тест-сеты** для казахского, русского, английского.
- **Raw outputs** прогона токенизаторов (CSV, после Дня 2).
- **Computed metrics** (CSV, после Дня 3).

## Формат тест-сета (TSV)

Шесть колонок, разделены табами. Первая строка — header. Строки начинающиеся с `#` игнорируются.

| Колонка | Описание | Пример |
|---|---|---|
| `word` | слово в естественной орфографии | `үйлеріміздегі` |
| `morpheme_split` | разделение на морфемы дефисами | `үй-лер-іміз-де-гі` |
| `gloss` | Leipzig glossing — морфема:значение, через `.` для портманто | `house-PL-1PL.POSS-LOC-REL` |
| `pos` | часть речи | `NOUN` |
| `category` | категория тестового кейса | `agglutinative_chain` |
| `notes` | свободное поле — сомнения, варианты, источник | `(?) вариант -дағы` |

## Leipzig Glossing — мини-справочник

Категории которые будут чаще всего:
- **Падежи (септік):** `NOM` (атау), `GEN` (ілік), `DAT` (барыс), `ACC` (табыс), `LOC` (жатыс), `ABL` (шығыс), `INS` (көмектес)
- **Число:** `SG`, `PL`
- **Лицо + число:** `1SG`, `2SG`, `3SG`, `1PL`, `2PL`, `3PL`
- **Притяжательность (тәуелдік):** `POSS` (с лицом: `1SG.POSS`, `2SG.POSS` и т.д.)
- **Время:** `PRES`, `PST`, `FUT`
- **Отрицание:** `NEG`
- **Деривация:** `REL` (относительный аффикс -ғы/-гі), `NMLZ` (номинализатор), `CAUS` (каузатив)
- **Часть речи:** `NOUN`, `VERB`, `ADJ`, `ADV`, `PRON`, `PART`, `POSTP`

Подробно: https://www.eva.mpg.de/lingua/pdf/Glossing-Rules.pdf (Leipzig Glossing Rules, 14 страниц, классика).

## Категории тестовых кейсов

Заводи по нескольку примеров каждой:
- `basic_noun` — простое существительное в номинативе.
- `case_marked` — существительное в неноминативном падеже (по одному примеру на каждый из 7 падежей минимум).
- `possessive` — с притяжательным аффиксом.
- `plural` — множественное число.
- `agglutinative_chain` — 3+ суффикса подряд (твой главный demo для статьи).
- `verb_finite` — глагол с лично-числовыми окончаниями.
- `verb_negative` — отрицательная форма глагола.
- `verb_tense` — разные времена.
- `derivational` — слово с деривационным суффиксом.
- `compound` — сложные слова.
- `loanword` — заимствованные слова (русские/арабские) — особый кейс, BPE может работать иначе.

## Качество > количество

- Если сомневаешься в разметке — оставляй `(?)` в `notes` и иди дальше. Спорное обсудим позже.
- Лучше 200 чистых слов чем 500 с ошибками.
- Можешь свериться с Apertium-kaz (open-source морфоанализатор) для самопроверки, но **финальное решение твоё** — ты native speaker.
